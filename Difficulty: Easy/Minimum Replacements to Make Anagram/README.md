<h2><a href="https://www.geeksforgeeks.org/problems/min-manipulations-to-make-strings-anagram1421/1?page=4&category=Strings&company=Amazon,Microsoft,Google,Flipkart,Adobe,NPCI,Samsung,Accolite&difficulty=Easy,Medium&status=unsolved&sortBy=submissions">Minimum Replacements to Make Anagram</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given two lowercase strings <strong>s1</strong> and <strong>s2</strong> of <strong>equal</strong> length, find the <strong>minimum </strong>number of steps required to make them <strong>anagrams</strong> of each other.&nbsp; </span><span style="font-size: 18px;">In one step, you can change any single character in either string to any other lowercase English letter. Characters cannot be inserted or deleted.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s1 = "aba", s2 = "baa"
<strong>Output:</strong> 0
<strong>Explanation</strong>: Both strings contain the same characters with the same frequencies, so they are already anagrams. Hence, no changes are required and the answer is 0.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: s1 = "ddcf", s2 = "cedk"
<strong>Output:</strong> 2
<strong>Explanation</strong>: The character frequencies in s1 are [d:2, c:1, f:1], while in S2 they are [c:1, e:1, d:1, k:1]. <br>By changing 'e' to 'd' and 'k' to 'f' in S2, both strings will have the same character frequencies and become anagrams. Therefore, the minimum number of steps required is 2.</span>
</pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ s1.size() ≤ 10<sup>5<br></sup></span><span style="font-size: 18px;">|s1| = |s2| = n<br></span><span style="font-size: 18px;">|s| represents the length of the string s.</span></p></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Flipkart</code>&nbsp;<code>Yatra.com</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Strings</code>&nbsp;<code>anagram</code>&nbsp;
